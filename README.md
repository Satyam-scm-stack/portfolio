# Satyam Kumar: portfolio site

Static site (HTML, CSS, JS). No build step.

## Publish on GitHub Pages
1. Create a repo, e.g. `krsatyam112.github.io` (site at https://krsatyam112.github.io) or `portfolio`.
2. Upload everything in this folder (keep `index.html` at the top level).
3. Settings > Pages > Source: "Deploy from a branch" > `main` / root > Save.

## Edit content
Everything is in the top block of `main.js` (CONFIG, KPIS, PROJECTS, TOOLS, AWARDS, CERTS, SKILLS).
Add your LinkedIn and email in CONFIG; they appear only when filled in.

## Not included on purpose
Internal HCCB workbooks (BP 2027/2026, rate sheets, Wada model, depot business case), the raw eCRS CSV and the Six Sigma deck. Add them only if your employer allows it.
